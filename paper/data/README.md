# Data del paper

Esta subcarpeta guarda datasets auxiliares útiles para escribir el paper sin tener que volver al árbol completo del proyecto.

## Qué debería vivir aquí

- datasets persona-nivel ya enriquecidos y listos para análisis sustantivo
- salidas futuras de clasificación LLM
- tablas intermedias que convenga citar o auditar en el manuscrito

## Qué no conviene duplicar acá

- toda la data raw del scraping
- copias completas innecesarias del proyecto

## Archivo esperado a futuro

- `future_llm_labels.csv`: salida consolidada del clasificador LLM en R con ideología, diplomacia y vínculos transnacionales.
